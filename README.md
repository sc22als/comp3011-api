# COMP3011 Coursework 1: Goodreads Book API

## Project Overview
A RESTful API built with Flask and SQLite to manage and query book metadata. Features full CRUD operations and Basic Authentication for destructive actions.

## Setup Instructions
1. Clone the repository: `git clone https://github.com/sc22als/comp3011-api.git`
2. Install dependencies: `pip install flask flasgger`
3. Run the server: `python main.py` or `flask run` if setup
4. Access documentation at `http://127.0.0.1:5000/apidocs`
